# ERAYA Interactive Luxury V4

This version specifically addresses readability and interaction.

### Changes
- Larger body text and navigation text
- Larger product descriptions
- High-contrast typography
- GSAP page-loader animation
- GSAP hero entrance animation
- GSAP ScrollTrigger section reveals
- Locomotive Scroll smooth scrolling on desktop
- GSAP parallax image movement
- Animated horizontal marquee
- Scroll progress bar
- Magnetic buttons/links
- 3D tilt interaction on product cards
- Craft list hover animation
- Rotating visual ring
- Mobile-friendly fallback without Locomotive Scroll
- Responsive layout

External CDN libraries are loaded in index.html:
- Locomotive Scroll 4.1.4
- GSAP 3.12.7
- ScrollTrigger

Open index.html in Chrome with an internet connection for the animation libraries.
