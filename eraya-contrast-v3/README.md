# ERAYA — High Contrast Luxury V3

This is a different UI direction from the previous/reference-inspired versions.

Core idea:
- Dark hero with highly readable cream typography
- White/cream content sections for maximum readability
- Olive brand sections for identity
- Clear cards and CTA hierarchy
- Large but controlled editorial typography
- Less visual noise and less text placed directly over photographs
- Designed to be easy for a client to understand while still looking premium

Brand basis:
#4E5923 / #F3DBBB / #464646 / #FFFFFF
